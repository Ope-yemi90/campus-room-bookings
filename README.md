# Campus Room Booking System

A responsive web application that allows students to browse available campus rooms, view room details, and make bookings.

## Features
- Browse available rooms
- View room details
- Book a room
- View and cancel bookings
- Save bookings in the browser

## Technologies Used
- Next.js
- React
- TypeScript
- Tailwind CSS

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Ope-yemi90/campus-room-bookings.git
cd campus-room-bookings
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
